En esta página encontrarás el avance que voy teniendo en este bootcamp

¿Qué es lo aprendido hasta el momento?

Mi objetivo

Mi objetivo es poder desarrollar páginas web completas y atractivas que ofrezcan una buena experiencia al usuario.

¿Qué es lo que espero aprender en el futuro?

  • Poder desarrollar una página web completa que se pueda ver de forma atractiva para el usuario, que tenga una buena interfaz, y a modo de ejemplo que tenga imagen y sea dinamica.
